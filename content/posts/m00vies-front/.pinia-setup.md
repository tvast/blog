# 🍍 Configuration Pinia

## Installation

Si ce n'est pas déjà fait:

```bash
yarn add pinia
```

**Status**: ✅ Configuration déjà appliquée dans `src/main.ts`

## Vérification

Pour vérifier que Pinia est bien installé:

```bash
# 1. Voir si pinia est dans package_old.json
grep "pinia" package_old.json

# 2. Installer si nécessaire
yarn install

# 3. Lancer le dev server
yarn dev
```

## DevTools Pinia (optionnel)

Pour déboguer les stores dans le navigateur:

```bash
yarn add -D @pinia/devtools
```

Puis dans `src/main.ts`:

```typescript
import { createPinia } from 'pinia';

const app = createApp(App);
const pinia = createPinia();

// En développement
if (import.meta.env.DEV) {
  pinia.use(DevtoolsPlugin);
}

app.use(pinia);
```
