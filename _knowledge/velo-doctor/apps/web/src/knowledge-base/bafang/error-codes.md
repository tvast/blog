# Codes d'erreur Bafang courants

## Symptoms

- Un code d'erreur numérique s'affiche sur le display (ex: 21, 22, 25, 30...)

## Probable causes

- 21/22 : problème lié au capteur de vitesse ou au frein
- 25 : erreur de communication display ↔ contrôleur
- 30 : erreur liée au capteur PAS ou à son câblage
- Les codes exacts varient selon le firmware et le modèle de display (LCD3, LCD5, SW900)

## Tests

1. Noter précisément le code affiché et le modèle exact du display
2. Vérifier les connecteurs concernés selon la nature du code (vitesse, PAS, communication)
3. Débrancher puis rebrancher le display pour écarter un faux contact
4. Comparer avec la documentation constructeur du modèle exact si disponible

## Fixes

- Reconnecter fermement le capteur ou câble identifié par le code
- Remplacer le capteur concerné si le défaut persiste après vérification du câblage
- Mettre à jour ou réinitialiser le display si l'erreur est liée à la communication

## Safety warnings

- Ne pas ignorer un code d'erreur répété : il signale une protection active, pas un simple bug d'affichage
