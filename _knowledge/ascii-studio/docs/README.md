# π VJing Studio

**Audio-Reactive Generative Visuals at Light Speed**

Real-time 3D generative art meets ASCII rendering. Create stunning VJ performances with music-driven mathematics.

## Overview

π VJing Studio is a powerful, open-source visual performance tool that transforms audio into mesmerizing real-time generative visuals. Built with cutting-edge web technologies.

## Key Features

✨ **Audio-Reactive** - Real-time frequency analysis, spectral data, RMS metering
🎨 **3D Graphics** - WebGL shaders, parametric geometry, particle systems  
📝 **ASCII Art** - 11 generative scenes with custom character sets
🌙 **12 Themes** - Dark/Light modes with perfect contrast
⚡ **30+ Parameters** - Real-time control over every aspect
🎬 **Multi-Format** - Audio files, videos, or live microphone input

## Getting Started

### Install
```bash
git clone https://github.com/tvast/pi-studio.git
cd pi-studio
npm install
```

### Develop
```bash
npm run dev
```

### Build
```bash
npm run build
```

## Tech Stack

- **Vue 3** - Composition API
- **Three.js** - 3D graphics
- **Web Audio API** - Audio analysis
- **Quasar** - UI framework
- **Pinia** - State management
- **Vite** - Build tool
- **Electron** - Desktop app

## Scenes

1. Torus Knot - Parametric 3D geometry
2. Plasma Field - Navier-Stokes simulation
3. Particle System - Physics animation
4. Spiral Visualization - Frequency spectrum
5. ASCII Grid - Character-based rendering
6. Low-Poly Snake - Animated 3D snake
7. Torus Glow - Enhanced lighting
8. Wave Forms - Audio waveform
9. Kaleidoscope - Symmetrical patterns
10. Orb Matrix - Sphere packing
11. Grid Flow - Vector field
