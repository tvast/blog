A Dracula-themed Jekyll theme built around one idea: a knowledge base of a few
thousand documents should still feel navigable.

- **⌘K / Ctrl-K** opens search across every indexed document.
- The **sidebar** filters in place as you type.
- Sections expand on demand, so page weight stays flat no matter how large the
  corpus grows.
